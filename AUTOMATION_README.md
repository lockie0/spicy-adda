# Spicy Adda Automation Testing

Cypress automation has been added without modifying the existing website code, design, UI, product data, cart logic, checkout flow, payment flow, or business logic.

The test files are in the separate `cypress/` folder. Install Cypress with `npm install`, start the root `index.html` using VS Code Live Server at `http://127.0.0.1:5500/`, then run `npm run test:open` or `npm test`.

See `cypress/README.md` for the complete setup instructions.
